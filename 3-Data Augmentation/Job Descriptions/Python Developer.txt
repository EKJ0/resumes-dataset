Job Title: Python Developer

Overview: We're seeking a Python Developer to build and maintain web applications
and data-driven services using Python and related frameworks.

Key Responsibilities:
- Develop web applications using Python and Django
- Design and optimize database interactions (MySQL/SQL)
- Build and integrate REST APIs
- Write clean, tested, maintainable code

Requirements:
- Bachelor's degree in Computer Science or related field
- 2-4 years Python development experience

- Familiarity with HTML, CSS, and JavaScript
