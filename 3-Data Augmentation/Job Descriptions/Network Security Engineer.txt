JOB DESCRIPTIONS — NETWORK SECURITY ENGINEER
Based on a sample of 14 CVs drawn from 125 resumes in the Network Security Engineer category.

================================================
DRAFT 1 — Standard / Mid-Level
================================================
Job Title: Network Security Engineer

Overview: We're seeking a Network Security Engineer to design, implement, and
maintain secure network infrastructure and defend against threats.

Key Responsibilities:
- Design and implement network security controls and architecture
- Monitor networks for vulnerabilities, threats, and intrusions
- Manage firewalls, routing, and Cisco network infrastructure
- Conduct risk assessments and remediate identified vulnerabilities
- Support incident response and security investigations

Requirements:
- Bachelor's degree in Computer Science or related field
- 3+ years network/security engineering experience
- Proficiency with Cisco networking and security tools
- Relevant certifications (CCNA, Security+, CISSP) a plus

================================================
DRAFT 2 — Senior / Cybersecurity Lead
================================================
Job Title: Senior Network Security Engineer

Overview: We're looking for a Senior Network Security Engineer to lead security
architecture and drive enterprise risk reduction initiatives.

Key Responsibilities:
- Architect enterprise-wide network security solutions
- Lead vulnerability assessments and penetration testing initiatives
- Oversee incident response and threat mitigation efforts
- Mentor junior security engineers and define security standards
- Partner with IT leadership on risk and compliance strategy

Requirements:
- 6+ years network security/cybersecurity experience
- Advanced knowledge of Cisco systems, firewalls, and threat detection
- CISSP or equivalent advanced security certification
- Proven track record reducing organizational security risk

DRAFT 5 — Formal / Corporate
================================================
Job Title: Network Security Engineer

Position Summary: The Network Security Engineer is responsible for designing,
implementing, and maintaining secure network infrastructure to protect
organizational assets from cyber threats.

Essential Duties and Responsibilities:
- Designs and implements network security architecture and controls
- Monitors network traffic and systems for potential threats
- Conducts vulnerability assessments and risk analysis
- Manages firewall, routing, and access control configurations
- Supports incident response and security compliance efforts

Minimum Qualifications:
- Bachelor's degree in Computer Science, Information Security, or related field
- Minimum three (3) years of network security engineering experience
- Relevant certifications (CCNA, Security+, or CISSP) preferred
