JOB DESCRIPTIONS — WEB DESIGNING
Based on a sample of 14 CVs drawn from 112 resumes in the Web Designing category.

================================================
DRAFT 1 — Standard / Web Designer
================================================
Job Title: Web Designer

Overview: We're seeking a Web Designer to create responsive, visually engaging
websites that deliver a great user experience.

Key Responsibilities:
- Design responsive websites using HTML, CSS, and WordPress
- Create graphics and visual assets using Adobe Creative Suite
- Ensure sites are optimized for usability and mobile responsiveness
- Collaborate with developers on site functionality
- Maintain and update existing websites

Requirements:
- Degree in Web Design, Graphic Design, or related field
- 2+ years web design experience
- Proficiency in HTML, CSS, WordPress, and Adobe Photoshop/Illustrator
- Strong portfolio demonstrating responsive design work

================================================
DRAFT 2 — Senior / Web Developer-Designer
================================================
Job Title: Senior Web Designer / Developer

Overview: We're looking for a Senior Web Designer to lead site design strategy and
front-end implementation across digital properties.

Key Responsibilities:
- Lead design and front-end development of websites (HTML, CSS, PHP)
- Establish design standards for responsiveness and brand consistency
- Optimize site performance, functionality, and user experience
- Mentor junior designers and review design/development output
- Collaborate with marketing on digital campaign landing pages

Requirements:
- 5+ years web design/development experience
- Strong proficiency in HTML, CSS, PHP, and WordPress
- Expert-level Adobe Creative Suite skills
- Proven portfolio of high-traffic or high-conversion websites

DRAFT 5 — Formal / Corporate
================================================
Job Title: Web Designer

Position Summary: The Web Designer is responsible for designing and maintaining
responsive, user-friendly websites that support brand and business objectives.

Essential Duties and Responsibilities:
- Designs and develops responsive website layouts and features
- Creates visual assets aligned with brand guidelines
- Ensures website usability, performance, and mobile optimization
- Maintains and updates existing website content
- Collaborates with development and marketing teams

Minimum Qualifications:
- Degree in Web Design, Graphic Design, or related field
- Minimum two (2) years of web design experience
- Proficiency in HTML, CSS, WordPress, and Adobe Creative Suite
