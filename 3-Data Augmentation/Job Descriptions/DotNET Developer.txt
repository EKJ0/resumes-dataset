JOB DESCRIPTIONS — .NET DEVELOPER
Based on a sample of 14 CVs drawn from 125 resumes in the .NET Developer category.

================================================
DRAFT 1 — Standard / Mid-Level
================================================
Job Title: .NET Developer

Overview: We're seeking a .NET Developer to design, build, and maintain web
applications using the Microsoft technology stack.

Key Responsibilities:
- Develop web applications using ASP.NET, MVC, and C#
- Design and optimize SQL Server databases and queries
- Build responsive front-ends with HTML, CSS, and JavaScript
- Participate in the full software development lifecycle (SDLC)
- Debug, test, and maintain existing applications

Requirements:
- Bachelor's degree in Computer Science or related field
- 2-4 years .NET development experience
- Proficiency in ASP.NET, C#, MVC, and SQL Server
- Familiarity with HTML, CSS, and JavaScript/jQuery
